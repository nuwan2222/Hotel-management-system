## 📌 Overview

This application helps hotel administrators manage **rooms**, **users**, **bookings**, **customers**, **check-ins**, **check-outs**, and **reports** through a centralized admin dashboard.

---

## 🛠️ Features

| Module | Capabilities |
|---|---|
| 🛏️ **Room Management** | Add, edit, delete rooms · Change status (Available / Occupied) |
| 📅 **Booking Management** | Search, view, edit, and remove bookings |
| 👥 **User Management** | View users, change roles, remove users |
| 🧑 **Customer Management** | View and manage customer records |
| 🔑 **Check-In / Check-Out** | Track ongoing stays and completed check-outs |
| 📊 **Reports** | Generate and view hotel reports |
| ⚙️ **Settings** | Manage system-wide settings |

## 🚀 Getting Started

### Prerequisites
- Visual Studio (2019 or later recommended)
- .NET Framework installed

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/nuwan2222/Hotel-management-system.git

# 2. Navigate into the project folder
cd Hotel-management-system
```

Then open `HotelManagement.sln` in Visual Studio, build with `Ctrl+Shift+B`, and run with `F5`.
